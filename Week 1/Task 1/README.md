
# EDA on Iris Dataset

This project performs Exploratory Data Analysis (EDA) on the Iris dataset. The analysis focuses on understanding the structure of the dataset, identifying patterns and relationships between features, checking data quality, and visualizing differences between three diffrent Iris species.


## EDA Objectives
- Understand the structure of the Iris dataset
- Analyze the distribution of each feature
- Check for missing and duplicate values
- Identify relationships between numerical features
- Compare measurements across Iris species
- Use visualizations to discover patterns
- Identify the most useful features for distinguishing species

## Dataset Description
- Number of samples: 150
- Number of features: 4
- Number of Missing values: 0
- Number of Duplicate values: 3
- Target variable: Species
- Classes: Setosa, Versicolor, Virginica

## Python Libraries Used
- Pandas
- NumPy
- Matplotlib
- Seaborn
