# Linear REgression

    Linear regression is a statistical and machine learning method used to model the straight-line relationship between an input variable and an output variable. 
-	Independent Variable (X): The input factor or predictor used to make a forecast.
-	Dependent Variable (Y): The target outcome you want to predict.
-	Best-Fit Line: A straight line that passes through maximum data points that minimize the distance between the actual data and the predicted line.
The model uses a simple mathematical formula:<br>
                             y = mx + c
